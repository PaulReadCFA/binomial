The value of a call option at t = 1 once it can be exercised is:

$\color{#1e40af}{C_u} = \max(\color{#047857}{S_u} - K, 0)$ in the up state

$\color{#1e40af}{C_d} = \max(\color{#b91c1c}{S_d} - K, 0)$ in the down state

The value of a put option at t = 1 once it can be exercised is:

$\color{#6d28d9}{P_u} = \max(K - \color{#047857}{S_u}, 0)$ in the up state

$\color{#6d28d9}{P_d} = \max(K - \color{#b91c1c}{S_d}, 0)$ in the down state

From these option values the hedge ratio for the call (HRC) and the hedge ratio for the put (HRP) can be computed by combining the stock with the appropriate option so that the combination becomes riskless:

$$\color{#1e40af}{\text{HR}_C} = \frac{\color{#1e40af}{C_u} - \color{#1e40af}{C_d}}{\color{#047857}{S_u} - \color{#b91c1c}{S_d}}$$

$$\color{#6d28d9}{\text{HR}_P} = \frac{\color{#6d28d9}{P_u} - \color{#6d28d9}{P_d}}{\color{#047857}{S_u} - \color{#b91c1c}{S_d}}$$

This now allows us to compute the call and the put value at t = 0 as follows:

$$\color{#1e40af}{c_0} = S_0 \times \color{#1e40af}{\text{HR}_C} - \frac{\color{#1e40af}{\text{HR}_C} \times \color{#047857}{S_u} - \color{#1e40af}{C_u}}{1 + r}$$

$$\color{#6d28d9}{p_0} = S_0 \times \color{#6d28d9}{\text{HR}_P} - \frac{\color{#6d28d9}{\text{HR}_P} \times \color{#047857}{S_u} - \color{#6d28d9}{P_u}}{1 + r}$$
