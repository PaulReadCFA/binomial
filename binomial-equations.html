The value of a call option at t = 1 once it can be exercised is:

C u = max ( S u − K , 0 ) in the up state

C d = max ( S d − K , 0 ) in the down state

The value of a put option at t = 1 once it can be exercised is:

P u = max ( K − S u , 0 ) in the up state

P d = max ( K − S d , 0 ) in the down state

From these option values the hedge ratio for the call ( HR C ) and the hedge ratio for the put ( HR P ) can be computed by combining the stock with the appropriate option so that the combination becomes riskless:

HR C = C u − C d S u − S d

HR P = P u − P d S u − S d

This now allows us to compute the call and the put value at t = 0 as follows:

c 0 = S 0 × HR C − HR C × S u − C u 1 + r

p 0 = S 0 × HR P − HR P × S u − P u 1 + r
